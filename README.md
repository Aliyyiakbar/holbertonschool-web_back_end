# Holberton School - Web Back End

This repository contains my back-end projects for Holberton School.

It covers Python, JavaScript, SQL, REST APIs, Flask, templating, server-side rendering,
variable annotations, DOM manipulation, and other backend development concepts.

## Requirements

### Python Projects

- OS: Ubuntu 20.04 LTS
- Interpreter: `python3` version 3.8.* or 3.9 depending on the project
- Style: `pycodestyle` or `pycodestyle` equivalent as required by each project
- All files must end with a new line
- Python files must start with the required shebang for the project
- All files must be executable when required

### JavaScript Projects

- OS: Ubuntu 20.04 LTS
- Node.js version: 14.x
- All files must end with a new line
- JavaScript files must start with the required shebang for the project
- Code must be semistandard compliant when required
- All files must be executable when required

### SQL Projects

- OS: Ubuntu 22.04 LTS or as required by the project
- Database: MySQL 8.0
- All SQL files must end with a new line
- SQL files must follow the task format required by the project

### Web Projects

- HTML and CSS files must follow the requirements of each project
- Semantic structure and correct markup are expected
- A `README.md` file is required in each project directory

Each project directory has its own `README.md` with task details and file descriptions.

## Projects

- `python_variable_annotations` — type annotations, duck typing, mypy validation, and advanced Python typing
- `python_async_function` — asynchronous execution, coroutines, asyncio tasks, and concurrent programming

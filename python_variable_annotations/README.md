# Python - Variable Annotations

This directory contains my solutions for the Holberton School project
**"Python - Variable Annotations"**.

The goal of this project is to practice type annotations in Python 3,
including function signatures, variable types, duck typing, and validation
with `mypy`.

## Learning Objectives

- Type annotations in Python 3
- How to use type annotations to specify function signatures and variable types
- Duck typing
- How to validate code with `mypy`

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- All files will be interpreted/compiled on Ubuntu 20.04 LTS using `python3` version 3.9
- All files must end with a new line
- The first line of all files must be exactly `#!/usr/bin/env python3`
- A `README.md` file at the root of this project folder is mandatory
- Code should use `pycodestyle` style (version 2.5.*)
- All files must be executable
- File length will be tested using `wc`
- All modules must have documentation
- All classes must have documentation
- All functions must have documentation

## Files

- `0-add.py`  
  Adds two integers and returns the result.

- `1-concat.py`  
  Concatenates two strings and returns the result.

- `2-floor.py`  
  Returns the floor of a floating-point number.

- `3-to_string.py`  
  Returns a string representation of a float.

- `4-define_variables.py`  
  Defines and annotates variables with the correct types.

- `5-sum_list.py`  
  Returns the sum of a list of floats.

- `6-sum_mixed_list.py`  
  Returns the sum of a list containing integers and floats.

- `7-to_kv.py`  
  Returns a tuple containing a string and the square of an integer or float.

- `8-make_multiplier.py`  
  Returns a function that multiplies a float by a given factor.

- `9-element_length.py`  
  Returns a list containing the length of each element in a list.

- `100-safe_first_element.py`  
  Uses duck typing to return the first element of a sequence safely.

- `101-safely_get_value.py`  
  Uses type annotations for more advanced value access.

- `102-type_checking.py`  
  Demonstrates type checking with annotations.

## Usage

Example:

```bash
chmod +x 100-safe_first_element.py
./100-main.py
```
